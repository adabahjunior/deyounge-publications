# Deyounge Publications Limited

Website for **Deyounge Publications Limited** — a book publishing company in Tarkwa, Ghana.

## Features

- Browse publishing services and past work
- Shop books with demo covers
- Demo checkout / payment flow
- Unlock on-site flip-book reader after payment
- Mobile header with hamburger menu

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Demo payment

Pay with **Mobile Money (MoMo)** on checkout — pick a network and enter any Ghana number. Nothing is charged. Purchased titles unlock in the browser (`localStorage`) and open in the flip-book reader.
